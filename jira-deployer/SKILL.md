# Phase 3: Custom MCP Server Ticket Creation
1. Gather the root cause summary compiled from Phase 1 (`RCA_Summary.txt`).
2. Read the 4 metadata criteria accepted from Phase 2.
3. Call our custom registered MCP server tool: `custom-sre-mcp:deploy_jira_change_request`.
4. Map the inputs directly to the tool parameters:
   - `jiraSpace`
   - `ticketType`
   - `environment`
   - `impactLevel`
   - `rootCauseSummary`
5. Print out the raw JSON text receipt block and the final string confirmation generated by the server tool.
